# Half-Life 拓展 · 训练场与 AI 对战

最新版：2026.10.11-training-bots，网络版本 cw_20261011_net7。

选择 Steam 的 Half-Life 原游戏目录安装，安装器自动备份并保留存档、个人设置和两组按键。需要拥有 Half-Life 并登录 Steam。安装后从 Steam 游戏库的 Half-Life 点击“开始”，全部额外选项位于“选项 → 拓展”。

“训练场与 Bot”提供原创 cw_aim_training：可选择全部武器、目标数量、移动、血量、护甲、方向区域、掩体及弹药模式，查看击杀、命中和准确率。进入前自动保存剧情，支持返回原进度。

“多人房间”支持自由对战、团队对战、剧情合作、AI 乱斗和 AI 团队对战。4 张社区地图及 19 张原版对战地图可供对战选择；AI 可设双方人数、玩家队伍、四档难度、默认武器、血量、护甲、复活及比赛上限，Bot 自动补齐剩余位置。训练与房间设置保存，更新时保留。

包含 30 把 TF 武器、17 把 CS 武器和 28 把分别命名的近战武器，使用戈登 HEV 手部。1 取出上次选择的刀，B 用同一把刀快捷近战后恢复原武器，J 检视和奔跑转刀，Mouse5 重击。刀具也可在 F2 装备菜单、Alt 轮盘和“刀具与检视”页面选择，每项动作可绑定两个按键。狙击镜及已确认的瞄准位置保留。

雷电使用原始瞄具，发射电能弹并释放受墙壁遮挡的电弧；弓箭手持续瞄准约 1.25 秒锁定后可发射追踪火箭。

运动模式在“运动预设”选择预设1、Apex、Titanfall2；保留画面、FOV、准心、声音、手电筒、分层地图、剧情指引及作弊功能。显示比例可选 16:10、4:3 或原生，铺满当前屏幕；在 16:9 显示器上产生对应水平拉伸。本机现有 16:10 设置已保留。

修复重复配发武器留下的遮挡模型、重复护甲服、拥挤出生及旋转门卡住；合并静态世界模型减少 69 个预加载条目，并将复杂模型的平滑法线改为整模计算一次，保留造型、贴图和原有光照算法。
