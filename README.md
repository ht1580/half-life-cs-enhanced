安装器选择 Steam 的 Half-Life 目录，自动备份并保留原有存档、设置和两组按键。需要拥有 Half-Life 并登录 Steam。

安装后直接在 Steam 游戏库点击 Half-Life 的“开始”，或桌面“Half-Life 拓展”。所有额外设置位于“选项 → 拓展”。显示比例可选16:10或4:3，铺满当前屏幕；在16:9显示器上产生相应水平拉伸。

30把TF武器、17把CS武器、戈登手部、原有狙击镜、校正瞄准中心点、三种运动预设、图像/声音/照明/地图引导/作弊选项及210项双键动作。

“拓展 → 多人房间”可创建、加入和退出，自由对战、团队对战、剧情合作均支持。对战提供四张社区地图，红蓝队可手选或自动分队。所有人安装同一新版，旧网络版本会被拒绝。合作换关保留各自武器、弹夹和弹药；多人禁用单人作弊，运动预设由房主控制。

同一局域网或虚拟局域网使用房主地址:端口，默认27015。互联网连接需要可达地址及必要的UDP端口转发，或双方加入同一虚拟局域网。第二台物理电脑及公网穿透尚未实机验证。
