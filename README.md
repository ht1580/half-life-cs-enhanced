先保存并退出 Half-Life，运行安装 EXE，选择 Steam 的 Half-Life 安装目录。安装器自动备份并保留存档、个人设置和两组按键。在 Steam 游戏库点击 Half-Life 的“开始”；全部拓展设置位于游戏内“选项 → 拓展”。需要登录并拥有 Half-Life 的 Steam，安装包不包含原版游戏或用户存档。

本版修正与操作：

- 瞄准练习默认蓝队只有玩家，红队全是 Bot，靶标默认静止、不会反击。可切换移动、人数、血甲、掩体、弹药及方向靶区。地图 `cw_aim_training` 为原创 GoldSrc 适配，参考 CS2 Aim Botz 功能，未冒称移植 CS2 地图文件。
- 在“准心与瞄准”启用“开镜距离匹配”，MDH 可选 0–100，默认 100；0 匹配中心，100 匹配水平屏幕边缘。
- EVA-8 按住开火连续发射。Apex 冷钢、恶灵苦无及换色奔跑时轻按检视键开始循环转刀，松键继续；再次按键、停跑、攻击、切枪或打开菜单结束。CS 刀具轻按检视一次、按住连续。默认 J，个人绑定优先。
- Bot 使用地图原生出生点，修正导航点覆盖出生区、爬梯节点提前跳过和临边逃脱动作。减少地图楼层重复判断、AI 视线和距离计算、着色器重复正则构造；模型缓存加入无效索引保护。保留现有模型、贴图与画面效果。

保留 30 把 TF 武器、17 把 CS 武器、28 把命名近战、三种运动预设、社区地图、分层地图和剧情引导。默认 16:10 输入拉伸铺满当前显示器，可在画面设置选择 4:3；16:9 显示器上产生水平拉伸，输出保持显示器分辨率。

本轮私有后台实机检查覆盖练习场真实伤害/复活/24靶标、EVA-8 连续射击、两种 Apex 刀原始动画的连续循环及中断、pool/crossfire/xen 的出生点与AI移动、原生瞄准设置。正式安装后逐项核对安装文件与存档设置。未进行本轮前台鼠标点选或 Steam 全屏启动，以免影响用户正在玩的 Apex。

已读取 Windows 和游戏日志，未复现或归因用户报告的具体崩溃；不能保证所有崩溃消失。CPU 回归证明减少了所测路径的重复工作，实际 FPS 和总加载时间随地图、后台负载与硬件变化，不提供未经测量的提升百分比。多人沿用之前验证的房间流程；本轮未重新进行双电脑或公网测试。原生出生点较少的地图在高人数下可能发生出生清场。

网络协议保持 `cw_20261011_net7`，联机双方应安装兼容版本并使用可达地址；需要时使用虚拟局域网或 UDP 端口转发。资源署名与许可见安装后的 `CREDITS*.txt`，源码见 `codex_cs/codex/source.zip`，回滚备份位于游戏目录 `Codex Backups`。
