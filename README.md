# Half-Life CS 单人增强

适用于已安装的 Half-Life。包含 CS 武器、Gordon HEV 手部、HEV 界面、速度计、物品轮盘、分楼层地图与剧情指引、运动增强、画面与声音设置。

[下载最新版安装器](https://github.com/ht1580/half-life-cs-enhanced/releases/latest/download/HalfLife-CS-Enhanced-Setup.exe) · [查看版本与校验值](https://github.com/ht1580/half-life-cs-enhanced/releases)

运行 EXE，选择包含 `hl.exe`、`hw.dll` 和 `valve` 的游戏目录。安装器会先备份存档与修改文件，安装后校验；保存用户偏好与双键绑定，失败时回滚。

## 当前版本

- 三种运动预设：预设 1 保留旧版机制，只增加行走与 Ctrl 奔跑；Apex 加入滑铲加速、跳跃疲劳和有限蹬墙；Titanfall 2 加入滑墙和空中二段跳。支持自动冲刺。
- FOV 70–120、MDH100 瞄准、自定义准心、HDR／曝光／暗部／泛光／阴影／水面／纹理等画面选项，默认 16:10 输入拉伸至 16:9 全屏输出。
- 音乐、武器、角色对白与 HEV、环境、脚步互动、命中反馈分类音量，保留此前声音资源与武器手感。
- 手电筒均衡／广角／远射光束、亮度调整、电量显示；F 开关，L 切换光束，均可改绑。
- 17 把 CS 武器，AWP／Scout／AUG／SG552／弩的实际瞄准镜；B 快捷撬棍，Alt 轮盘，F2 装备与设置，M 楼层地图。
- CS 入口 98 个动作均支持双键；保留滚轮前进、滚轮跳跃与 Mouse5 副开火。

新预设是在 GoldSrc 中实现的运动适配，不能视为 Apex 或 Titanfall 2 原引擎的完整移植。分类音量在 CS 入口生效；原版／稳定入口兼容旧存档并支持画面和移动增强。增强手电筒光束需要动态光照。

安装包不含原版游戏、原版引擎或用户存档。源码修改、SDK 许可和资源署名随包提供；详细功能与实机检查见版本说明。
