# Half-Life 拓展 · 全局性能与加载优化

最新版：2026.10.11-performance；网络版本 cw_20261011_net7。

[下载 ZIP：安装 EXE、中文说明、SHA256](https://github.com/ht1580/half-life-cs-enhanced/releases/download/v2026.10.11-performance/HalfLife-Expansion-2026.10.11-Performance.zip)

选择 Steam 的 Half-Life 原游戏目录安装，自动备份并保留存档、个人设置和两组按键。安装后从 Steam 游戏库 Half-Life 点击“开始”，全部额外选项位于“选项 → 拓展”。需要拥有 Half-Life 并登录 Steam。

本版优化全局世界材质绑定、可见节点处理、小地图裁剪与后台预读取消；合并190张字节相同的图片引用，图像/映射的新安装资源减少46.32 MiB，不重新编码、不降低清晰度。既有武器、运动、剧情、地图和画面选项完整保留。升级不清理历史版本、个人资源或回滚备份。

包含30把TF武器、17把CS武器、28把命名近战武器及戈登手部；1取出上次选择的近战，B同武器快捷近战，J检视，Mouse5重击。雷电电弧、弓箭手锁定追踪、已有狙击镜、MDH100保留。

“训练场与 Bot”可设置全部武器、目标数量、移动、血量、护甲、方向区域、掩体和弹药，查看命中及准确率。“多人房间”支持自由对战、团队对战、剧情合作、AI乱斗和AI团队对战，包含4张社区地图与19张原版对战地图，支持人数、队伍、难度及默认武器。进入训练/房间前自动保存，可返回剧情。

运动预设1、Apex、Titanfall2；FOV70–120、自定义准心、音效类别、手电筒、HEV HUD、速度计、分层小地图及M大地图、剧情指引、进度跳转与旧存档兼容模式均在游戏内设置。显示比例可选16:10/4:3/原生，默认16:10铺满当前输出；在16:9显示器产生对应拉伸。

本版按受影响范围检查九张代表地图、实际换关、世界模型、AI、分层地图、旧存档与真实Steam入口，并人工检查截图。局部CPU基准的加速不等于整机FPS倍率，加载并非零延迟。原版游戏/引擎和用户存档不随包分发。不同物理电脑与公网穿透未实机验证；联机需相同net7协议及可达地址。

本机同配置九张地图对比的 FPS 比值中位数约提升7%，普通室内场景改善较明显，Xen 场景改善较小。实际暖缓存换关的平均耗时没有明显改善；本次主要消除后台预读取消时的主线程等待，不承诺所有场景提速。
