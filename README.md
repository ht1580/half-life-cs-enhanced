# Half-Life 拓展 · 近战修复与反泰坦武器

最新版：2026.10.11-melee-fix，网络版本 cw_20261011_net6。

选择 Steam 的 Half-Life 原游戏目录安装，安装器自动备份并保留存档和个人设置。需要拥有 Half-Life 并登录 Steam。安装后在 Steam 游戏库点击 Half-Life 的“开始”，所有额外设置位于“选项 → 拓展”。

修复旧包的武器登记表覆盖问题：刀具现在使用真实近战攻击，支持轻击和 Mouse5 重击。保留 28 把独立命名的近战武器及戈登 HEV 手部，包括 CS 蝴蝶刀、爪子刀、刺刀的八种涂装，以及冷钢、翠绿锋芒、恶灵苦无、希望黎明。

1 直接取出上次选择的近战武器；B 用同一把武器挥击一次，随后恢复原武器、弹药和上一把武器。J 点按检视一次，按住持续转刀，奔跑与站立自动切换动作，攻击或切枪会中断。F2 装备菜单、Alt 近战轮盘或“选项 → 拓展 → 刀具与检视”可选择武器。每个动作支持两组按键；本次升级只迁移默认1/B一次，原有 O 取刀可以保留为第二组键，原有 K 语音键保留，以后自行设置也会保留。

雷电通过原始瞄具瞄准，发射电能弹并向附近敌人释放电弧，墙壁阻挡电弧。弓箭手持续瞄准敌人约1.25秒锁定，显示目标框与进度；锁定后发射追踪火箭，未锁定也可直射，松开瞄准、切枪、换弹或遮挡会解除锁定。

三种运动预设位于“选项 → 拓展 → 运动预设”：预设1、Apex、Titanfall2。保留30把TF武器、17把CS武器、既有狙击镜和中心点、画面声音设置、手电照明、分层地图、剧情引导和作弊菜单。显示比例可选16:10或4:3，铺满当前屏幕，在16:9显示器上产生水平拉伸。

“拓展 → 多人房间”支持社区地图自由对战、团队对战和剧情合作，双方需要相同网络版本。局域网或虚拟局域网使用房主地址和端口，默认27015；不同物理电脑及公网穿透尚未实机验证。
