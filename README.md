# Half-Life 拓展 · 命名近战武器版

最新版：2026.10.10-knives，网络版本 cw_20261010_net4。

[下载 ZIP（安装 EXE、中文使用说明、SHA256）](https://github.com/ht1580/half-life-cs-enhanced/releases/download/v2026.10.10-knives/HalfLife-Expansion-2026.10.10-Knives.zip)

安装器选择 Steam 的 Half-Life 目录，自动备份并保留原有存档、个人设置和两组按键。需要拥有 Half-Life 并登录 Steam。安装后在 Steam 游戏库点击 Half-Life 的“开始”，或桌面“Half-Life 拓展”。所有额外选项位于“选项 → 拓展”。

新增 28 把分别命名的近战武器：蝴蝶刀、爪子刀、刺刀各有原色、渐变之色、大理石渐变、多普勒·红宝石、多普勒·蓝宝石、表面淬火、深红之网、多普勒·黑珍珠；另有冷钢、翠绿锋芒、恶灵苦无、希望黎明。刀具使用戈登 HEV 手部，支持实际近战伤害、拔刀、攻击、切回上一把武器、站立检视和奔跑转刀。

F2 装备菜单或 Alt 轮盘的“近战”分类可选择每把刀；“选项 → 拓展 → 刀具与检视”设置默认近战武器。检视默认 J，取刀默认 K；点按检视一次，按住循环，攻击或切枪会中断。已有按键优先保留，发生冲突时请在“双键绑定”中选择空闲键。240 项动作均有两个绑定位置，每把刀也可单独绑定。

保留 30 把 TF 武器、17 把 CS 武器、既有狙击镜和瞄准中心点、三种运动预设、图像、声音、手电照明、分层地图、剧情引导及作弊菜单。显示比例可选 16:10 或 4:3，铺满当前屏幕；在 16:9 显示器上产生相应水平拉伸。

“拓展 → 多人房间”可创建、加入和退出，支持社区地图自由对战、团队对战、剧情合作。对战有四张社区地图，红蓝队可手选或自动分队。所有玩家需安装同一新版，旧网络版本会被拒绝。合作换关保留各自武器、弹夹和弹药；多人禁用单人作弊，运动预设由房主控制。

同一局域网或虚拟局域网使用房主地址:端口，默认 27015。互联网连接需要可达地址及必要的 UDP 端口转发，或双方加入同一虚拟局域网。第二台物理电脑及公网穿透尚未实机验证。
