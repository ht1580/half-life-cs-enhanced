# Half-Life 拓展

当前正式版：2026.10.12-training2-ability。

[下载 ZIP：安装 EXE、中文说明和校验码](https://github.com/ht1580/half-life-cs-enhanced/releases/download/v2026.10.12-training-ability/HalfLife-Expansion-2026.10.12-TrainingAbility.zip)

先保存并退出 Half-Life，运行安装 EXE，选择 Steam 的 Half-Life 目录。随后从 Steam 原游戏入口启动。安装器自动备份并保留存档与个人设置，新增动作只占空闲默认键位，原有两组按键保持。

本版操作：

- 主菜单“瞄准练习”进入原创 GoldSrc 适配练习场。蓝队只有玩家，红队为 Bot，默认静止但随机生成，复活会换位。北侧17个参数/作弊按钮，南侧枪械和命名近战按钮；射击或靠近按E使用，准心旁显示按钮名称。可调靶标人数、移动、生命、护甲、弹药、掩体、靶区、无敌和穿墙，参数即时保存。参考CS2 Aim Botz功能，未冒称移植CS2 BSP文件。
- “选项 → 瞄准与拓展”默认打开“瞄准与MDH / 准心”，开镜距离匹配和MDH位于顶部。MDH自由选择0–100；机瞄以Apex历史1X/Holo视角测量为参考，2X/3X保留对应视觉倍率；已认可的狙击镜和模型位置保持。上滚轮向上滚动，下滚轮向下滚动。
- “能力 · 激光眼”先开启，再按住Q发射、松开停止。持续时间0为无限，每秒伤害0为瞬杀，可输入非负有限数值；大数经安全伤害换算。能力关闭时Q保留旧动作，另设能力双键后使用新按键。仅单人或独自主持的训练场可用，射线被墙体阻挡。
- 主菜单后台预读实际库存模型，最多96MiB、每个进程一次；开始关卡立即取消，游戏帧不等待。优化模型法线临时分配，保持结果、原模型贴图和画质。具体FPS/总加载时间取决于场景、硬件与后台负载，未宣称零延迟。

保留TF/CS武器、28把命名近战、三种运动预设、社区地图和分层引导。EVA-8按住连喷，Apex刀奔跑时轻按检视循环；默认J，个人绑定优先。默认16:10画面拉伸铺满显示器，可选择4:3；16:9输出上形成水平拉伸。

本轮为私有后台静音实机及渲染截图检查，包含真实按钮开火、随机有效靶位、激光伤害/阻挡/时限/关闭、原生设置Apply/Cancel、EVA-8和Apex检视；另记录实际预读与三个关卡加载。安装后核对完整文件及用户数据。为了不影响用户玩Apex，未做本轮前台鼠标或Steam全屏启动，也未重做双电脑/公网测试。以前报告的具体崩溃尚未复现或归因，不保证全部崩溃消失。

需要拥有并登录Half-Life的Steam，安装包不含原版引擎或用户存档。网络协议仍为cw_20261011_net7；联机双方需可达地址，必要时使用虚拟局域网或UDP端口转发。资源署名见CREDITS文件，源码见codex_cs/codex/source.zip，回滚位于游戏目录Codex Backups。清理旧文件仍保持停止。
