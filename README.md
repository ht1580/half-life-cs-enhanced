先保存并退出 Half-Life，运行安装 EXE，选择 Steam 的 Half-Life 目录；之后从 Steam 原游戏入口启动。安装器备份并保留存档、原有设置和按键。

主菜单或 Esc 暂停菜单直接点击“激光眼”，打开独立设置窗口。勾选启用，设置持续秒数和每秒伤害后点“应用”；取消保留上次应用的值。持续时间0为无限，每秒伤害0为瞬杀。默认按住鼠标中键发射、松开停止；Q始终保留原有动作。双键绑定中可设置两个能力键，也可绑定“打开激光眼独立窗口”。旧版本没有能力键且中键空闲时自动补齐；已有能力双键或中键自定义动作保留。能力只用于单人或独自主持的训练场，墙体阻挡。
